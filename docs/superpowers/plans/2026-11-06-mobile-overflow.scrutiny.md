# Scrutiny: TP-0120

- **Intent:** ไม่มีหน้าใดกว้างกว่า viewport บนมือถือ
- **ทางที่ง่ายกว่า:** ใส่ `overflow-x: hidden` ที่ body
  - **ไม่เลือก** เพราะซ่อนอาการ แต่ต้นเหตุยังอยู่ ปุ่มที่ล้นจะถูกตัดหายไปเฉย ๆ
- **ไล่โค้ดและวัดผล:**
  - วัดจาก DOM จริงแล้ว element ที่กว้างที่สุดที่ไม่ใช่ fixed คือ `header.mb-4` (316) และ grid (316) ใน `div.px-6`
  - หลังแก้ แถวหัวหน้า wrap ได้ และคอลัมน์ grid หดได้ถึง 0
- **ความเสี่ยง:**
  - บนมือถือหัวหน้าอาจกลายเป็น 2 บรรทัด ซึ่งตั้งใจไว้
  - desktop ไม่เปลี่ยน เพราะ `sm:px-6` และ `lg:` grid ยังเหมือนเดิม
- **Verdict:** ship เมื่อ e2e flow 3 และ flow 6 ผ่าน
